FMDC · Machine Setup

Get your Mac ready for the handoff.

Ten steps. Roughly twenty minutes. Then Claude takes over.

Hey Jake — this guide gets your laptop set up so Claude can come in and do the heavy lifting: trawling your Gmail and Drive, building your Obsidian vault, and wiring up an intake pipeline for new jobs. Work top to bottom. Copy the commands in the shaded boxes and paste them into Terminal. When you hit step 10, you're done — Claude takes it from there.

What you'll need before you start

  • A Mac running macOS 13 or newer
  • Your Google account password (for Gmail + Drive access)
  • Your Claude account login (the one with your paid plan)
  • About 20 minutes of uninterrupted time

Open Terminal first

Press Cmd+Space, type Terminal, hit return. A black-or-white window opens with a blinking cursor. That's where every command below goes.

The ten steps

1

Install Apple's command line tools

This gives your Mac the basic developer tools it needs. A dialog box will pop up — click Install and wait for it to finish (a few minutes).

xcode-select --install

If it says "already installed," you're good — move on.

2

Install Homebrew

Homebrew is the package manager we'll use to install everything else. Paste this whole line and hit return. It'll ask for your Mac password — type it (you won't see the characters, that's normal) and press return.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

At the end it may print two lines starting with echo — copy and run them. That adds Homebrew to your path.

3

Install Node.js

Claude Code runs on Node. This installs it.

brew install node
4

Install Claude Code

This is the CLI that actually runs the handoff. Installs globally in about 30 seconds.

npm install -g @anthropic-ai/claude-code
5

Install Obsidian

This is where your vault — people, jobs, gear, knowledge base — is going to live. Claude will build the folder structure; you open it in Obsidian to actually use it.

brew install --cask obsidian
6

Create your FMDC working folder

This is the single folder on your Mac that holds everything — the vault, the intake pipeline, the notes Claude writes. We're putting it in your home directory so it's easy to find.

mkdir -p ~/FMDC && cd ~/FMDC
7

Initialize it as a git repo

Turns the folder into something git can track. This means every change Claude makes is saved with a history — nothing ever silently disappears.

git init
8

Save the handoff file into this folder

Download or move cowork-handoff.md (the other file I sent you) into ~/FMDC. You can drag it there in Finder, or if it's in Downloads already, run this:

mv ~/Downloads/cowork-handoff.md ~/FMDC/
9

Start Claude Code

Still inside the ~/FMDC folder, run:

claude

First time you run it, it'll open a browser window and ask you to sign into your Anthropic account. Do that, then come back to Terminal — you should see a Claude prompt waiting for you.

10

Open cowork-handoff.md, copy everything, paste into Claude

Open the file in any text editor (TextEdit is fine — right-click → Open With → TextEdit). Select all (Cmd+A), copy (Cmd+C), click back on the Terminal window with Claude running, and paste (Cmd+V). Hit return.

Claude will start working. At some point early on it'll prompt you to sign into Google so it can read Gmail and Drive — that's the one thing it needs from you during the session. Click through, approve the access, and you're done. Go make coffee.

That's it. You're handed off.

When Claude finishes, it'll print a summary of the top 5 things it found about your business and tell you where the Obsidian vault lives. Open Obsidian → Open folder as vault → pick ~/FMDC. Everything will be waiting for you.

If anything gets stuck, text me. Don't force it.
