PHOTOGRAPHY SLOTS
=================

Drop image files into this folder and run `npm run build` (from /deck).
Each slot is detected automatically. If a file is absent, that page
falls back to the vector aircraft illustration — the deck is complete
either way.

  cover.jpg     Cover — full-bleed hero. Best suited to a cinematic
                in-flight shot. Landscape, 16:9, min 2400 x 1350 px.

  profile.jpg   Aircraft Profile (page 4) — clean side-on view, fills
                the framed plate. Landscape, min 1600 x 1000 px.

  livery.jpg    Livery Concept (page 5) — three-quarter or detail
                view. Landscape, min 2200 x 1200 px.

Accepted extensions: jpg, jpeg, png, webp (e.g. cover.jpg or cover.png).

Notes
-----
- A dark scrim is applied over the cover photo so the title stays legible.
- The cover, profile and livery vector illustrations remain the default
  until matching files are added here.
